Sandboxing program for services

§Usage

warden is used seperate from the service’s sandbox component as a major part of sandboxing is namespace cloning, which is bound to the parent executable. Since we don’t want to modify kickit’s environment, spawning a seperate process through another executable fits best.

Theoretically, warden can sandbox any executable if needed. This is not recommended, however, as bubblewrap is a much better alternative with an almost identical mechanism.
