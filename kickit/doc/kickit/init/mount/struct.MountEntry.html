Idiomatic struct representation of a generic Linux mount entry

§Abstract

A structure of source, destination, filesystem, flags and opts.

This may represent an existing mount (from /proc/mounts) or an entry that hasn’t been mounted yet, which can be initialized with the mount method.

§Linux (and other Unix-like)

Mount entries are represented as a whitespace-delimited list (like you would find in /etc/fstab or /proc/mounts).

§Construction

§Single

The parse method constructs an entry from a whitespace-delimited list. If you already have the values, see the new method.

§Multiple entry

Mount entries are provided in the MountTable type (a transparent wrapper of a vector of MountEntry).

  • To access the system fstab, use the fstab function.

  • To access the system mounts, use the mounttab function.

  • If you have a custom configuration file to parse, see MountTable::try_from_config_file.

pub fn parse(str_entry: &str) -> Result<Self>

Try parse whitespace-delimited string input of a mount entry

Note: This method doesn’t utilize the freq & passno values (5th and 6th), but expects them to be required. Majority of the time these are both 0s.

Example entries you would expect to see in /etc/fstab or /proc/mounts:

/dev/source_device     /path/to/dest   fs_type   flags,and,options 0 0
LABEL=label_of_src_dev /path/to/dest_2 fs_type_2 flags,and,options 0 0

Note that /proc/mounts always has the exact location of the source device- prefixed with /dev/

§Errors

  • Entry doesn’t have 6 elements (source, dest, fs, flags & opts, freq, passno)

  • Invalid provided device map (valid example: PARTLABEL=label_of_gpt_part)
