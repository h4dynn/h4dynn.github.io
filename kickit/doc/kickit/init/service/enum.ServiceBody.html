Pattern dependent mutable fields, as a major part of the Service structure

Variants§

§

PreExecution

State of the service before up function is called

§

Standard

Standard pattern services have unique fields

Fields

§pid: OnceLock<u32>

Process’s ID, set once only by the up function

§up: bool

This is made true by the up function

§process: DynamicOwnership<Child, SupervisorTask>

The spawned child process of the init system. This value is only set once the process is initialized by up. If this service is standard, it gets moved to the supervisor task, which constantly monitors the process to make sure it never exits (daemon-style execution)

§log: DynamicOwnership<Logger, LogWatchTask>

The service’s logger instance (see definition in logger). Similarly to the process field, this is set by up, and also moved to the logger task if this is a standard service. This task interprets the process’s stderr and relays it back to the logfile (if undesired, ServiceConfig::logger can be set to false)
