Expand description

Pretty wrapper over nix::sched::CloneFlags. Used in its array form (NsFlags) when specifying sandboxing options, outlining which namespaces are shared & cloned.

This is not a unique implementation, it is identical to the nix implementation, which itself is simply Rust bindings to libc.

For more information on these flags (CLONE_FLAGS in libc), see the unshare(2) man page for more information.
