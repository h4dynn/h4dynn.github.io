Sandbox implementation for services

§Abstract

The aim is to create a secure “jail” for a service, the idea being it starts out with the bare minimum for basic execution, and the service lists the files/namespaces it wants to be access.

§Credits

The idea of namespace sandboxing was originally introduced by bubblewrap. The reason why we don’t use it (even though the implementations are incredibly similar) is because bubblewrap’s primary function is user namespace sandboxing, while all services in kickit run as the root user.
