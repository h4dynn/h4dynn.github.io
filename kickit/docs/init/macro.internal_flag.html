Compare the value of an internal flag

§Implementation

No enum is actually used, but rather a phantom enum defined in the macro, expanded at compile time. This allows for matching the string value from the kernel command-line in an enum-like fashion, and also allows for easy extension later on. While this may increase the compile-time, it should bear minimal impact on runtime performance.

§Available flags

Listed are all the internal behavior modifying flags currently used by kickit.

§ErrorHandler

  • Kernel command-line flag identifier: ERROR_HANDLER

Modify how the init handles encountered fatal, non-recoverable errors during main execution. This does not include errors before main execution (sanity checks).

§Shell (default)

  • String value: shell

Open a user-interactive, unprivileged shell upon errors. This is useful for debugging & fixing systemic issues without requiring external media for recovery.

Example of a shell opened by this method:

[kickit] (05 Nov 15:52:14) [-] Critical error when starting init, starting unprivileged emergency shell now
(emergency) / $

The user account used by the shell, is emergency_shell, which is created by the package installation script (see EMERGENCY_SHELL_UID).

§PowerOff

  • String value: poweroff

Wait for 3 seconds to allow the user to take notice of the error, before powering off.

§Block

  • String value: block

Block the init’s execution indefinitely, until manual ACPI (holding power button) poweroff.

§Panic (not recommended)

  • String value: panic

Exit the init process with an error code (1), causing a kernel panic immediately after. Obviously this is not ideal, and is not recommended, nor can I see any valid use case for this, but it is still included regardless.

Example of kernel panic caused by init execution exit:

[    8.968602] Kernel panic - not syncing: Attempted to kill init!

§Example

§Boolean flag

if (internal_flag!(InternalFlag::get("THIS_IS_A_DOCUMENTATION_EXAMPLE")))
{
  eprintln!("wow!! this is a doc example!!");
}

§Enum-like flag

internal_flag!
{
  match (InternalFlag::get("ERROR_HANDLER"))
  {
    Panic => eprintln!("exiting.."),
    PowerOff | Block => eprintln!("blocking.."),
    // note: the default value should always come last, since its match pattern is greedy (_)
    Shell => eprintln!("opening a shell..")
  }
}
