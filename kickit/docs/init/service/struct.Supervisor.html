Standard service process supervisor

The final destination of a standard Service, the process is constantly monitored - to make sure it never exits.

The instance is initialized from up, running asynchronously as a tokio task.

§Behavior

  • The underlying main method used by the supervisor is wait. This blocks until the child process exits, at which point the supervisor assesses if the service is optional. If it is, a warning is given, if not, a global init error is thrown. 1

  • When poweroff kills the services provided in STANDARD_SERVICES, this will cause the supervisor to throw an error under normal circumstances. To mitigate this, the value POWER_OFF_READY is set to true before services are killed. The supervisor exits normally without throwing any errors.

  1. See the supervise function for reference. ↩
