pub fn cmdline_value(id: impl AnyStr) -> Option<String>
Expand description

Attempt to source kernel command-line option in string form

§Implementation

This accesses the kernel’s cached command-line from the /proc/cmdline file. It iterates through each whitespace-delimited argument provided and looks for the identifier followed by an = sign, and finally the value is returned, if found.

Once it reaches the end of the iterator without a match, None is returned.

§Return

If /proc/cmdline is inaccessible for some reason (such as system filesystems not being mounted), None is returned. Make sure that proc is mounted before using this function.
