Init core value interface

§Function

Provides contents of the various values used at the core of the init system, used to determine ktctls behavior. This socket is public, accessible to any user as it doesn’t provide any sensitive values.

Available values:

§state

State of the init currently (see crate::state::InitState). In sane environments, this should always be Okay. ktctl utilizes this value to safeguard some operations (such as shutdown).

§version

Constant, defined in source, compared with ktctl’s version for future proofing. If a non-matching version is detected, ktctl will refuse to operate - in case of potential incompatibilities introduced by new/old versions.

§target

OnceLock value of the init target. This is system by default.

§pid

OnceLock value of kickit’s pid (if ran as init, it is 1). This is used by ktctl to prevent init-only operations from being performed in a non-init environment.
