Expand description

Move elements from the front/back of a vector into output array Remove all of SIZE bytes from the front/back of the vector, moving them into an array. If you are dumping from the front, a VecDeque will be more suitable than a Vec, since it is double-ended.

§Safety

This doesn’t check if your array is big enough to index through the length provided. You need to implement those checks yourself before using this, otherwise index will fail, and throw an out-of-bounds access panic.

fn dump_front<const SIZE: usize>(&mut self) -> [T; SIZE]

We use MaybeUninit here since we COULD just use a [T; SIZE], depend on T implementing Default and use the default value but that creates unnecessary initialisations & adds an extra unneeded dependency.

§Usage
use std::collections::VecDeque;

let mut abcdef = VecDeque::from(['a', 'b', 'c', 'd', 'e', 'f']);
// Dump a, b and c only into an array
let abc: [char; 3] = abcdef.dump_front();

assert_eq!(abc, ['a', 'b', 'c']);
assert_eq!(abcdef.as_slice(), &['d', 'e', 'f']);
