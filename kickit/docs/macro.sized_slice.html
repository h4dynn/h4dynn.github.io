Macro sized_slice 

Source 
macro_rules! sized_slice {
    ($array: ident [$begin: literal .. $end: literal]) => { ... };
}
Expand description

Get a fixed-size slice from an array when the size can be calculated at compile-time

§Reason

When getting a fixed size slice of an array, the compiler says it doesn’t know its size as it treats these the same as it would for slices when the beginning & end aren’t known beforehand.

§Example

§Problem

ⓘ
// We know the size of the array at compile-time
let my_array: [u8; 6] = [0, 1, 2, 3, 4, 5];

/*
 * ..but the compiler doesn't know the size of the slice. So we get a compile error:
 * "error[E0277]: the size for values of type `[u8]` cannot be known at compilation time"
 */
let slice_of_first_two_values: [u8; 2] = my_array[0..2];

§Solution

let my_array: [u8; 6] = [0, 1, 2, 3, 4, 5];

// The macro uses a workaround, each value is assigned individually, one-by-one
let slice_of_first_two_values: [u8; 2] = sized_slice!(my_array[0..2]);
